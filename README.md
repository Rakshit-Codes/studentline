## 🚀 Project Description

Designed a comprehensive educational app specifically for college students to easily access academic resources and essential campus information. The app emphasizes seamless user experience and includes real-time assistance features powered by Gemini AI.

---

## 🛠️ Tech Stack

- Flutter  
- Gemini API  
- Firebase  

---

## ✨ Key Features

- 🔐 User authentication and editable profile  
- 📚 Access syllabus, notes, timetables, and faculty details (name, email)  
- 📢 Notice board for important academic announcements  
- 🗃️ Repository of previous year exam papers for exam preparation  
- 🤖 Integrated Gemini AI for instant academic help
